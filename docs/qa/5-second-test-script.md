# Peel v1 — 5-Second Usability & Aesthetic Test Script

This test is designed to validate the immediate visual impression of Peel, specifically verifying if the design achieves the "fresh, minimal, poetic, natural" feel defined in PRD § 8.3.

## Test Procedure
1. Recruit **3 design-savvy users** or friends.
2. Instruct them: *"I am going to show you a screen of a web application for exactly 5 seconds. Please look at it carefully and absorb the overall feeling. Afterwards, I will hide the screen and ask you a few simple questions."*
3. Open Peel to the **Now** view (idle state with task input and start button).
4. Show the screen for exactly **5 seconds**, then close or hide it.
5. Ask the user the following questions.

---

## 📋 Interview Questions

1. **Aesthetic Impression**: *"What are the first 3 words that come to mind to describe the visual feeling of the interface?"*
   * *Target words/feelings:* fresh (清新), minimal (极简), natural (自然), poetic (禅意/诗意), warm (温暖).
2. **Clarity**: *"What do you think this application does?"*
   * *Target answer:* A clean timer / task execution assistant.
3. **Standout elements**: *"What single element or detail caught your eye the most?"*
   * *Target elements:* The orange brand name `peel.`, the warm cream white background, or the corner peel orange logo.

---

## 📈 Success Criteria
- **Pass condition**: At least **2 out of 3** participants must mention descriptors matching our target feelings (e.g. *fresh, clean, minimal, natural, poetic*).
- **Fail condition**: If users describe it as "dry", "boring", "generic", or "messy", we must re-evaluate font/padding variables.
